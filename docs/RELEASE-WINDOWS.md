Нативный C++ сервер для Windows x64 без Docker, WSL и Python. Вся работа с программой — в браузере.

Исправлена повторная установка после ошибочного ввода подключения: мастер предлагает сохранить настройки или изменить PostgreSQL. Старые значения подставляются, пустой пароль сохраняет прежний. Остальные настройки, фотографии и складская база сохраняются.

- `Toolstock-Setup-2.1.1-windows-x64.exe` — установка сервера и автоматической службы Windows.
- `Toolstock-2.1.1-windows-x64.zip` — ручной запуск без установки службы.
- `SHA256SUMS.txt` — контрольные суммы.

Нужен PostgreSQL (рекомендуется 17), локальный или на отдельном сервере. Создайте пустую базу с отдельным владельцем, затем укажите подключение в установщике. Для этого пакета PostgreSQL устанавливается отдельно.

[Пошаговая инструкция](https://github.com/Faronik/Test/blob/main/docs/WINDOWS.md). После установки откройте http://localhost:8000 и создайте администратора. Для переноса SQLite сначала выполните импорт в пустую базу, затем открывайте веб-интерфейс.

Обновление сохраняет настройки и данные; перед ним сделайте резервную копию PostgreSQL и фотографий. Установщик не подписан сертификатом издателя.
