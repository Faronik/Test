# Изменения 20.10.2026

## Исправления

- Все POST-изменения выполняются в транзакции `BEGIN IMMEDIATE`. HTTP-ответ об успехе отправляется после успешной фиксации. При ошибке изменения откатываются.
- Приёмка после переточки: отмена и изменение количества действуют на обе части `batch_id`; проверяется история всех затронутых карточек. Неполные или ранее повреждённые пары требуют сверки.
- Списание, возврат, выдача и переточка защищены от одновременного расхода одного остатка. Отрицательные исторические остатки показываются явно.
- Идентификатор формы и контроль содержимого предотвращают повторное проведение после двойного клика или сетевого повтора. Изменённое содержимое уже проведённой формы отклоняется.
- Снимок очереди при массовой отправке сверяется с текущим: незаметно отправить изменившийся состав нельзя.
- Безопасная вставка JSON в HTML; текст станков и параметров не может закрыть элемент script. Варианты сдачи создаются через безопасные DOM-операции.
- Исправлены id фильтров отчёта, Unicode-поиск каталога, дробный радиус в серверной проверке и шаге HTML-поля. Поддержана запятая в геометрии инструмента и размерах при приёмке переточки.
- Причина списания проверяется сервером. Выдача на отключённый станок запрещена.

## Интерфейс

- Переключение между шестью операциями; видна одна форма, выбор сохраняется в URL, поддержаны «Назад/Вперёд» браузера.
- Подтверждение складской операции с итогами; предварительный просмотр всей очереди переточки.
- Кнопки выдачи, поступления и списания из карточки с выбранной позицией.
- Явное количество сдачи, очистка старой выбранной позиции при смене рабочего; защита от запоздавших результатов поиска.
- Ошибки рядом с формой без потери данных, блокировка повторного отправления во время запроса.
- Мобильный каталог с видимыми остатками, ячейкой и действиями; раскрывающееся мобильное меню.
- Дополнительные фильтры категории, производителя, ячейки, состояния, дефицита и диапазона диаметра. Сортировка сохраняет фильтры; возврат из карточки восстанавливает каталог.
- Поиск с клавиатуры: стрелки, Enter и Escape; сообщения при ошибке загрузки.

## Проверка

26 регрессионных тестов на реальном HTTP-сервере и временных SQLite-базах прошли. 23 браузерные проверки в Chromium прошли. Отдельно повторно проверены обновление базы без новой таблицы и повторная отправка формы.

Проверялись в том числе параллельные расходы, обе стороны исправления переточки, откат при последующей выдаче, повторные запросы, права рабочего, CSRF, XSS, дробные параметры, фильтры, создание карточки из поступления, выдача и частичный возврат через интерфейс, сохранение формы после ошибки и мобильный вид.

Проверки выполнены на Linux / Python 3.12. Запуск на Windows, длительная нагрузка и миграции всех исторических версий не испытывались. Функции инвентаризации, импорта, штрихкодов и развитого закупочного процесса в это обновление не входят.

# Версия 2.0 — C++20 / PostgreSQL

Сервер Python/SQLite заменён на C++20/PostgreSQL. Web-интерфейс работает через REST API v1. Добавлены OpenAPI 3.0, интерактивный API-клиент без CDN, Dockerfile, Docker Compose, скрипты запуска Windows/Linux, C++-импортёр SQLite и согласованное резервное копирование базы с фото.

Сохранены складские операции, состояния инструмента, закрепление за рабочим/станком, переточка, связанные исправления/отмены, роли, фото и статусы закупочных заявок. PostgreSQL-транзакции защищают проверку остатков и запись; Idempotency-Key предотвращает повторное проведение запросов. API использует роли, HttpOnly cookie/CSRF или Bearer token. Добавлены ограничение попыток входа и смена пароля с прекращением сеансов.

Предыдущая Python-версия остаётся в истории Git (bf94f36). Старые URL форм заменены на API v1; адреса Web-разделов используют #. Данные переносятся явно, в пустой PostgreSQL, без изменения исходной SQLite-базы.
# 2.1 — Windows без Docker

- Нативный пакет C++20, статические зависимости, установщик Inno Setup и переносимый ZIP.
- Служба Windows от LocalService, автоматический запуск, перезапуск при сбоях, управление через PowerShell; локальный доступ по умолчанию, доступ из подсети включается отдельно.
- Защищённая конфигурация PostgreSQL вне папки программы, отдельные фотографии и журнал; обновление и удаление не удаляют складскую базу.
- JSON-конфигурация, пути относительно файла настроек, ресурсы относительно бинарного файла, поддержка Unicode-путей и встроенного SQLite-импортёра Windows.
- Сборка и интеграционные проверки Windows в GitHub Actions; PostgreSQL устанавливается отдельно или используется существующий сервер базы.
